# Security policy

## Supported versions

Rollout Diff is in initial development. Security fixes target the latest
development code; older revisions have no guaranteed backport support.

## Reporting a vulnerability

Email Mamadou Wane at [mamadouswane@gmail.com](mailto:mamadouswane@gmail.com)
with the subject `Rollout Diff security report`. Keep vulnerability details out
of GitHub issues and pull requests.

Include the affected version or revision, environment, expected impact, and a
minimal reproduction. Use synthetic data and redact credentials and private
rollout content. Request a suitable transfer method before sending sensitive
attachments.

The maintainer will assess the report and coordinate remediation and disclosure
with the reporter. Response and resolution times depend on severity and
availability.
